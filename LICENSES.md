# Licenses And Dataset Notices

## RVL-CDIP Dataset

This project uses the RVL-CDIP document image dataset for classifier training,
evaluation, and golden-set replay.

- Dataset: RVL-CDIP
- Source: `https://adamharley.com/rvl-cdip/`
- Classes: 16 document layout classes
- Use in this project: visual document layout classification only
- OCR: not used

The RVL-CDIP dataset is intended for academic and research use. The classifier
artifacts in this repository were produced from RVL-CDIP images, and the golden
set under `app/classifier/eval/golden_images/` contains selected RVL-CDIP TIFF
files. These files should be treated as dataset-derived academic/research
materials, not as unrestricted production data.

Repo files derived from RVL-CDIP:

- `app/classifier/models/classifier.pt`
- `app/classifier/models/model_card.json`
- `app/classifier/eval/golden_expected.json`
- `app/classifier/eval/golden_images/`

Do not use the RVL-CDIP-derived artifacts for commercial or unrelated production
purposes without first confirming the dataset terms from the original source.

## Pretrained Model Weights

The classifier is based on `torchvision.models.convnext_tiny` with
`ConvNeXt_Tiny_Weights.DEFAULT`.

The pretrained ConvNeXt weights are provided through Torchvision/PyTorch. The
runtime model in this repository is a fine-tuned derivative artifact created for
the Week 6 academic project. See the PyTorch and Torchvision project licenses
for the upstream library and pretrained-weight terms.

Related dependencies:

- PyTorch: `https://github.com/pytorch/pytorch`
- Torchvision: `https://github.com/pytorch/vision`

## Generated Classifier Artifact

`app/classifier/models/classifier.pt` is a trained model artifact generated by
the Colab notebook for this project. It is stored with Git LFS because the file
is about 111 MB.

The corresponding `model_card.json` records:

- model backbone and pretrained weights enum
- training run mode
- test metrics
- per-class accuracy
- SHA-256 hash of `classifier.pt`
- Colab environment fingerprint

The current committed artifact is from a balanced 100k-image RVL-CDIP run, not
the full official RVL-CDIP test evaluation.
